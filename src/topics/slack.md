Slack is not a topic. It is free time built into the schedule: spare classes we
can use if we need them. We might use a slack class to catch up when an activity
has run long, to revisit something the class found tricky, or to work through
more exam-type questions together. If we are on track, slack classes are yours
for independent study or revision.
