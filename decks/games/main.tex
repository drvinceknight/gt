\slidehead{What kind of game, and what is a strategy?}
\notesref{2.2.1 to 2.2.4}{Games: Extensive Form, Normal Form, Strategy}

\vspace{0.6cm}

{\large In a \textbf{normal form} game everyone chooses
\answerrule[3.8cm]{simultaneously}. In an \textbf{extensive form} game players
move \answerrule[3.8cm]{in sequence} and can see what has happened.}

\vspace{0.9cm}

{\large Our game is \answerrule[4cm]{normal form}, because
\answerrule[7cm]{we all submit at once}.}

\vspace{0.9cm}

{\large In the game we just played, a strategy is
\answerrule[9cm]{a single number in \(\{0, 1, \ldots, 100\}\)}.}

\vspace{0.9cm}

{\large If instead you picked \emph{after} hearing the person before you, a
strategy would have to say
\answerrule[8cm]{what to pick for every number heard}.}
