\slidehead{Moving between states}
\notesref{11.2.1}{Moran Process: Definition: Moran Process}

\vspace{0.9cm}

{\large The number of hawks changes only when the type born differs from the
type that dies.}

\vspace{1.1cm}

\begin{center}
{\Large \(p_{10} =\) \answerblank[2.6]{\(\tfrac12 \cdot \tfrac13
 = \tfrac16\)} \hspace{1.4cm} \(p_{12} =\)
 \answerblank[2.6]{\(\tfrac12 \cdot \tfrac23 = \tfrac13\)}
 \hspace{1.4cm} \(p_{21} =\)
 \answerblank[2.6]{\(\tfrac14 \cdot \tfrac23 = \tfrac16\)}
 \hspace{1.4cm} \(p_{23} =\)
 \answerblank[2.6]{\(\tfrac34 \cdot \tfrac13 = \tfrac14\)}}
\end{center}

\vspace{1.2cm}

{\large Go back and write these on the chain. What happens with the remaining
probability? \answerblank[4.4]{The state does not change}}

\vspace{0.9cm}

\begin{center}
\answerspace{22.6}{2.6}{%
  The count moves only when the type born differs from the type that dies, so
  each arrow is one birth probability times the other type's death
  probability. Drawing the same type for both leaves the population exactly
  as it was.}
\end{center}

\slidehead{What the room found}
\notesref{11.2.2}{Moran Process: Definition: The Fixation Probability}

\vspace{0.9cm}

{\large Runs that ended with all hawks: \blank[2.2] out of \blank[2.2],
so a fixation probability of about \blank[2.6].}

\vspace{1.3cm}

{\large The theory says \(x_1 = \dfrac{1}{1 + \gamma_1 + \gamma_1 \gamma_2}\)
with \(\gamma_i = \) \answerblank[3.4]{\(p_{i,i-1}/p_{i,i+1}\)}, giving
\answerblank[2.6]{\(6/11 \approx 0.55\)}.}

\vspace{1.3cm}

{\large Close enough? \blank[2.2] \hspace{1.6cm} How many runs would we need to
be sure? \answerblank[3.4]{About 100}}

\vspace{1cm}

\begin{center}
\answerspace{22.6}{2.4}{%
  Here \(\gamma_1 = 1/2\) and \(\gamma_2 = 2/3\), so
  \(x_1 = 1/(1 + \tfrac12 + \tfrac13) = 6/11\). Twenty runs carry a
  standard error of about \(0.11\), so anything from eight to fourteen hawk
  fixations agrees with that; pinning the answer to \(\pm 0.05\) takes
  around a hundred runs.}
\end{center}
